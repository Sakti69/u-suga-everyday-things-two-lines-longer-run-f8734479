# Everyday Things, Two Lines, Longer Run

Entry for the make.fun competition
`u-suga-everyday-things-two-lines-longer-run-f8734479`: two lines — a toaster
explained to a 10-year-old through one vivid analogy, and one sentence on
what that analogy maps and what it leaves out.

`main.ts` (Node 22, standard library only) writes the two lines to
`/output/entry.txt`. No network, no secrets, no dependencies.
